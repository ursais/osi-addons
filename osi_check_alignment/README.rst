========
Overview
========

This module allows company dependent configurations for check printing.
Additional settings for fields on the check have been added so each item can be individually adjusted.
- Sequence Number
- Date
- Payee Name
- Payee Address
- Amount
- Amount Word
- Memo

Configuration
=============

* Go to Settings - General Settings - Accounting - Check Printing
* Change check component values accordingly to move items on check report. (In Inches)

=====
