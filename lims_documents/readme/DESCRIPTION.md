Provides seamless integration between **LIMS** and **Odoo Documents** to manage
laboratory files, reports, and attachments.

### Key Features

- Create and attach documents directly from LIMS Orders.
- Automatically link documents to the related record (`res_model`, `res_id`).
- Access all attachments under the “Documents” tab in the LIMS Order form.
- Compatible with LIMS Sign module for e-signature workflows.
