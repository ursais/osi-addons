Provides seamless integration between **LIMS** and **Odoo Documents** to
manage laboratory files, reports, and attachments.

Key Features
~~~~~~~~~~~~

-  Create and attach documents directly from LIMS Orders.
-  Automatically link documents to the related record (``res_model``,
   ``res_id``).
-  Access all attachments under the “Documents” tab in the LIMS Order
   form.
-  Compatible with LIMS Sign module for e-signature workflows.

Configuration
=============

Dependencies
~~~~~~~~~~~~

-  ``lims``
-  ``documents`` (Enterprise)

Setup Steps
~~~~~~~~~~~

1. Install **LIMS** and **Documents** modules.
2. Ensure the LIMS user has access to the *Documents* app.
3. Configure folders and tags in the **Documents** app if needed.
4. Users can attach documents directly from LIMS Orders using the
   “Create Document” button.

Usage
=====

1. Go to **LIMS → Orders**.
2. Open or create a new order.
3. In the **Documents** tab, click **Create Document**.
4. Upload or attach your laboratory report, invoice, or related file.
5. The document will appear in the **Documents** module linked to the
   LIMS Order.
6. You can now use **LIMS Sign** to send uploaded documents for
   signature.
