This module adds domain report validation functionality to the Odoo helpdesk system.
It allows tracking, validating, and filtering domain-based reports submitted by email
security services like Mimecast, preventing false positives from cluttering the
helpdesk system.

**Table of contents**

.. contents::
   :local:

Features
========

* Track domain reports with fields for domain, submitter, report ID, and validation status
* Validate domain reports as: Pending, Valid, False Positive, or Whitelisted
* Prevent ticket creation from false positive or whitelisted domain reports
* Add warning messages to tickets created from questionable reports
* Filter helpdesk tickets by domain report status
* View all tickets related to a specific domain report
* Bulk management of domain reports with tree and form views

Usage
=====

Domain Reports Management
-------------------------

1. Navigate to Helpdesk > Domain Reports
2. Create a new domain report or view existing ones
3. Mark reports as:
   
   * **Valid**: Legitimate security concerns
   * **False Positive**: Incorrectly flagged domains
   * **Whitelisted**: Trusted domains to prevent future false alerts
   * **Pending**: Awaiting validation

Helpdesk Ticket Integration
---------------------------

1. When creating a ticket, optionally link it to a domain report
2. Tickets linked to false positives or whitelisted reports will show warnings
3. View domain report details directly from the ticket
4. Mark domain reports as false positives from the ticket form
5. Filter tickets by domain report status in the search view

Access Control
--------------

* **Helpdesk Users**: Read-only access to domain reports
* **Helpdesk Managers**: Full access to create, edit, and delete domain reports
