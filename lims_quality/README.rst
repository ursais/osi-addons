This module integrates the LIMS (Laboratory Information Management
System) with Odoo's Quality module.

It allows you to link LIMS order lines with quality control points and
quality checks. Additionally, it introduces dedicated menu entries in
the Quality module under Master Data and Operations.

Configuration
=============

Prerequisites
-------------

- Odoo Enterprise version with ``quality`` module installed.
- LIMS module installed and configured.

Setup
-----

1. Install the ``lims_quality`` module.
2. Ensure the ``Quality`` app is available in your database.
3. Assign appropriate user access rights for Quality Managers or Lab
   Managers.

Usage
=====

1. Go to **Quality → Quality Checks → Master Data** to view or create
   Quality Control Points.
2. Go to **Quality → Quality Checks → Operations** to manage Quality
   Checks.
3. On a **LIMS Order Line**, you can now associate:

   - A **Quality Control Point**
   - A **Quality Check**

4. These links allow traceability between LIMS test results and Odoo
   Quality operations.
