Integrates **Odoo LIMS** with **Odoo Sign** for digital signature
workflows.

This module enables laboratory users to send test reports or analysis
documents directly for e-signature without leaving the LIMS interface.

Key Features
~~~~~~~~~~~~

-  “Send for Signature” button on LIMS Orders.
-  Automatic creation of **Sign Templates** from uploaded documents.
-  Full **Sign Request** lifecycle tracking per LIMS Order.
-  Smart button to view related signature requests.
-  Auto-generated access tokens for each request and signer.

Configuration
=============

Configuration — LIMS Sign
=========================

Setup Steps
~~~~~~~~~~~

1. Install **LIMS** and **Odoo Sign** modules.
2. Ensure that each LIMS Order has documents uploaded via the
   **Documents** tab.
3. Open **Settings → Sign → Templates** and (optionally) mark a template
   as default for LIMS, or rely on automatic template generation.
4. Assign an email address to the partner related to each LIMS Order, as
   it’s required for signature requests.

Usage
=====

1. Open any **LIMS Order** that has uploaded documents (via LIMS
   Documents).
2. Click **Send for Signature**.

   -  The module will automatically:

      -  Create a Sign Template from each document.
      -  Generate a Sign Request with signer info.
      -  Link it to the current LIMS Order.

3. Open the **Sign Requests** smart button to review sent signature
   requests.
4. Track progress directly from the LIMS Order chatter and Sign
   Dashboard.
