# Configuration — LIMS Sign

### Setup Steps
1. Install **LIMS** and **Odoo Sign** modules.
2. Ensure that each LIMS Order has documents uploaded via the **Documents** tab.
3. Open **Settings → Sign → Templates** and (optionally) mark a template as default for LIMS, or rely on automatic template generation.
4. Assign an email address to the partner related to each LIMS Order, as it’s required for signature requests.
