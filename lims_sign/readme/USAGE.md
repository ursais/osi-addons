1. Open any **LIMS Order** that has uploaded documents (via LIMS Documents).
2. Click **Send for Signature**.
   - The module will automatically:
     - Create a Sign Template from each document.
     - Generate a Sign Request with signer info.
     - Link it to the current LIMS Order.
3. Open the **Sign Requests** smart button to review sent signature requests.
4. Track progress directly from the LIMS Order chatter and Sign Dashboard.
