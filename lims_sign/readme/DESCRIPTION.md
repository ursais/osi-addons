Integrates **Odoo LIMS** with **Odoo Sign** for digital signature workflows.

This module enables laboratory users to send test reports or analysis documents directly for e-signature without leaving the LIMS interface.

### Key Features
- “Send for Signature” button on LIMS Orders.
- Automatic creation of **Sign Templates** from uploaded documents.
- Full **Sign Request** lifecycle tracking per LIMS Order.
- Smart button to view related signature requests.
- Auto-generated access tokens for each request and signer.
