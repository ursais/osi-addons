This module creates a Documents folder for purchasing and, when
centralization is enabled, turns files attached to requests for
quotation and purchase orders into documents in that folder.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to **Settings > Documents** and enable **Purchase** file
  centralization. Choose the default folder and tags.
- Go to **Purchase > Orders > Requests for Quotation** (or Purchase
  Orders).
- Create or open a record and upload a file as an attachment.
- Open **Documents**, select the **Purchase** folder, and open the file.
  It is linked to the purchase order.
