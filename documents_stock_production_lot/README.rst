This module creates a Documents folder for lot and serial numbers. When
centralization is enabled, files attached to lots become documents in
that folder. From Documents, the **Attach to Lot/Tracking Number**
action links a file to an existing lot.

.. contents::
   :local:

Usage
=====

- Go to **Settings > Documents** and enable **Lot** file centralization.
  Choose the default folder and tags.
- Go to **Inventory > Products > Lots/Serial Numbers**.
- Create or open a lot and upload a file as an attachment.
- Open **Documents**, select the **Lot/Tracking Numbers** folder, and
  open the file. It is linked to the lot.
- To attach an existing document to a lot, select it in that folder and
  run **Attach to Lot/Tracking Number**.
