- Go to **Settings > Documents** and enable **Lot** file centralization. Choose the
  default folder and tags.
- Go to **Inventory > Products > Lots/Serial Numbers**.
- Create or open a lot and upload a file as an attachment.
- Open **Documents**, select the **Lot/Tracking Numbers** folder, and open the file. It
  is linked to the lot.
- To attach an existing document to a lot, select it in that folder and run **Attach to
  Lot/Tracking Number**.
